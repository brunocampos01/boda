# Boda - Wedding Invitation

Digital wedding invitation for Bruno & Noh Hyun-jin (브루노 & 노현진).

**Wedding Date:** August 15, 2026 at 11:40 AM  
**Venue:** Daegu, South Korea

## Features

- Mobile-optimized responsive design
- Interactive photo gallery
- Live countdown timer
- Venue information with map integration (Naver, Kakao, Tmap)
- Background music with volume control
- Smooth animations and transitions

## Technology

- HTML5 + CSS3
- jQuery for interactivity
- Swiper.js for photo carousel
- AOS (Animate On Scroll) for animations
- Lottie for animations
- Fancybox for lightbox effects
- Naver Maps, Kakao Maps, Tmap integration

## Local Development

Simply open `index.html` in a web browser. No build process required.

## Notes

- Bank account information has been removed for privacy
- External map APIs require valid API keys (Naver Maps key included)
- All fonts and assets are included locally
